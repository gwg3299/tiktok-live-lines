## 直播卡顿、0播放，先查网络再怀疑内容

开播卡顿和0播放，大概率是网络问题：共享节点为了控成本会限速，出口IP又被大量用户反复使用、早被平台标记。

TikTok的码率范围在516Kbps到25Mbps之间，按均值2Mbps算，1Gbps带宽满负荷也只能同时跑500路播放，2TB流量满载只够用4.5小时左右。节点服务商的流量是批量买来的，不控制速度就会亏本，所以便宜节点直播老卡，根源往往是带宽被限，而不是延迟太高。

比卡顿更致命的是IP污染。共享节点的IP被成百上千人反复用过，里面藏着多少被TikTok风控标记过的“脏IP”没人知道。风控一旦判定你的网络环境不干净，轻则推流受限、0播放，重则封号——花几个月养好的号，可能因为一个IP直接归零。

正规直播网络要满足三个条件：

1. **连通性**：稳定连上TikTok服务器，不断流不掉线
2. **IP纯净度**：出口IP没有被平台标记的历史
3. **带宽稳定性**：高峰期不限速，推流码率有保障

这三条，共享节点一条都保证不了。

> 选购时认准“独享带宽”。很多廉价专线标注的10M是峰值共享，高峰期实际可用可能不到2M——这种买了也白买。

矩阵团队的账要两张一起算，流量经常被漏算。举个例子：10个账号、每个5Mbps，带宽需求是60Mbps（含1.2倍冗余）；但按10Mbps推流码率、每天播4小时、每月22天算，单账号每月要消耗约400GB流量（10Mbps÷8×3600秒×4小时×22天），10个账号就是4TB上下。不少流量套餐看着带宽够，月底流量先见底。
